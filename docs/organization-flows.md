# Organization Flows

## Overview
Organizations (schools, universities, companies) can:
- Create mentorship programs
- Add mentors & mentees
- Use AI to match pairs
- Monitor program activity
- Track progress, attendance, and goal completion
- Generate insights for stakeholders

---

## 1. Organization Onboarding

Steps:
1. Admin signs up
2. Creates Organization
3. Uploads logo, brand name, domain
4. Invites:
   - Mentors (faculty, alumni, managers)
   - Mentees (students, new hires)

---

## 2. Program Creation

Admin creates a program:
- Name (e.g., “CS 2025 Mentorship Program”)
- Start date & end date
- Mentor-to-mentee ratio
- Goal templates for mentees
- Max allowed mentees per mentor
- Optional structured tracks (career, entrepreneurship, research)

---

## 3. Adding Participants

Upload via:
- CSV
- Manual entry
- Auto-enroll domain users (@university.edu)

Participants get roles:
- `mentor`
- `mentee`

Role applies per-program, not globally.

---

## 4. AI Matching

### Inputs:
Mentor features:
- Skills
- Expertise
- Alumni data
- Past mentoring performance

Mentee features:
- Goal summary
- Skills
- Academic info
- Preferences

### Output:
- Ranked list of mentors per mentee
- Match score (0–1 scale)
- "Reasons for match" explanation

Admin can:
- Accept match
- Reject
- Override manually

---

## 5. Collaboration Lifecycle (Org)

Once matched:
- Collab automatically created
- Goal is shared with mentor
- Sessions scheduled
- Progress tracked

Admins can:
- Track active collabs
- See session histories
- Monitor milestones (visibility controlled)

---

## 6. Program Dashboards

Shows:
- Active collaborations
- Session counts
- Completed goals
- Mentor performance reports
- Mentee progress
- Drop-off rate
- Engagement timeline

---

## 7. Organization Billing

Pricing plans:
- Org Starter: 100 mentees
- Org Pro: 500 mentees
- Enterprise: unlimited + SSO + custom domain

Admin can manage billing via Stripe portal.
