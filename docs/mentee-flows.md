# Mentee Flows

## Overview
Mentees can:
- Create profiles using LinkedIn or CV upload
- Build their public profile
- Set goals for 30 or 60 days
- Share public goal page to recruit mentors
- Accept mentor collab invitations
- Book sessions based on mentor availability
- Receive AI-generated agendas & summaries
- Track milestones, progress, notes
- Complete goals and reflect

---

## 1. Mentee Onboarding

Steps:
1. Sign up with Clerk
2. Connect LinkedIn URL OR upload CV
3. AI scrapes & builds profile:
   - Work experience
   - Education
   - Skills
   - Achievements
4. User reviews & edits profile sections
5. Select which parts are public (via toggles)
6. Arrives at “Create Your First Goal” screen

---

## 2. Creating a Goal

Goal Wizard:
1. Goal Name  
2. Category (Career, Startup, Fitness, Learning, Personal Growth)  
3. Time horizon (30 or 60 days)  
4. Desired outcome  
5. Current blockers  
6. What they expect from mentor  

AI-enhanced:
- AI expands into:
  - Milestones
  - Weekly breakdown
  - Success criteria
  - Potential questions to ask mentors

User can edit before saving.

Public page generated:
- `/g/[goalSlug]`
- Sharable with mentors

---

## 3. Sharing Goal Page

User can share via:
- Social media
- Direct message
- WhatsApp
- Email
- Personal website

Mentor who opens page:
- Reviews mentee info
- Can choose “Start Collaboration”

---

## 4. Accepting Collaboration

If mentor initiates:
- Mentee sees “Collaboration Request”
- Reviews mentor profile
- Approves or declines

Once approved:
- Collaboration becomes active
- Mentee can schedule sessions

---

## 5. Booking Sessions (Focuses)

Mentee books based on mentor availability:
1. “Book a Focus”
2. View mentor's weekly availability
3. Select time slot
4. Automatic calendar event generated
5. AI generates session agenda

---

## 6. During Collaboration
Mentee gets:

### Agenda before session:
- What to prepare
- Questions to ask
- Topics to cover

### Summary after session:
- Key decisions
- Lessons
- Action items
- AI updates milestone progress

---

## 7. Progress Tracking

Mentee dashboard shows:
- Timeline of sessions
- Completed milestones
- Next action items
- Weekly check-ins (mood, blockers)
- Upcoming sessions

---

## 8. Completing Goal

Steps:
1. Mark goal as completed
2. AI generates final summary
3. Mentor receives badge
4. Mentee gets shareable completion summary (for LinkedIn)
5. Mentee can reflect and plan next goal
