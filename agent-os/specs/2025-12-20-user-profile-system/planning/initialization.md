# User Profile System - Initial Idea

## Feature Description

Complete profile management with avatar upload, bio, skills, work history, and education fields stored in Supabase with public/private visibility toggles.

## Context

This is Item #1 in the Product Roadmap (Phase 1: Core Mentee Experience). It serves as the foundation for the entire Mentorshape platform, enabling users to create and manage their profiles before creating goals, becoming mentors, or participating in collaborations.
