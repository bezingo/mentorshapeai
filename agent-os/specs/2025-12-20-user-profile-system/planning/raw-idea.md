# User Profile System - Raw Idea

## Feature Description

Complete profile management with avatar upload, bio, skills, work history, and education fields stored in Supabase with public/private visibility toggles.

## Roadmap Context

- **Phase**: Phase 1: Core Mentee Experience
- **Item Number**: 1
- **Size Estimate**: M (1-3 days)
- **Priority**: First feature in Phase 1 - foundational for mentee experience

## Initial Notes

This is the foundational feature that enables users to create and manage their profiles. It unlocks the core mentee experience and is a prerequisite for subsequent features like LinkedIn import (Item 2) and CV upload (Item 3).

Key components:
- Avatar upload functionality
- Bio field
- Skills management
- Work history tracking
- Education history
- Public/private visibility toggles for profile fields
- Supabase storage and database integration
